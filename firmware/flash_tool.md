## Flash Tool

This tool automatically detects the first available COM port and flashes prebuilt images located in the `./binaries` folder.

### Installation Instructions

1. Download the `binaries` folder containing all necessary files.
2. Download the `FlashTool.7z` archive and extract its contents to the same directory as the `binaries` folder.
3. Run `FlashTool.exe` to start the flashing process.
